# AWS Cloud Services

This repository contains basic AWS cloud services concepts and configurations including:

## Services Covered

### VPC (Virtual Private Cloud)
- Created a custom VPC
- Configured networking for AWS resources
- Managed route tables and security groups

### Subnets
- Created Public and Private Subnets
- Configured subnet CIDR ranges
- Associated subnets with route tables

### EC2 (Elastic Compute Cloud)
- Launched EC2 instances
- Connected using SSH
- Managed security groups and key pairs

### EKS (Elastic Kubernetes Service)
- Created an EKS cluster
- Added worker nodes
- Deployed containerized applications using Kubernetes

## Technologies Used
- AWS VPC
- AWS EC2
- AWS EKS
- Kubernetes
- AWS CLI

## Learning Objectives
- Understand AWS networking fundamentals
- Deploy virtual machines on AWS
- Learn container orchestration with Kubernetes
- Explore cloud infrastructure management
